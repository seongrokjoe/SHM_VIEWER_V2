SCTC_Alarm_Compare.exe 사용 방법 v2
========================================

[핵심 기능]
기존 장비와 패치 Alarm CSV를 비교하여 차이 보고서를 만듭니다.
AutoChange로 기존 장비의 StopMode를 적용한 새 Alarm 폴더를 만듭니다.

[실행 순서]
1. exe를 두 입력 Alarm 폴더 밖의 쓰기 가능한 폴더에 둡니다.
2. 실행 후 Path1에 기존 장비 Alarm 폴더의 절대경로를 입력합니다.
3. Path2에 패치 Alarm 폴더의 절대경로를 입력합니다.
4. 생성된 Diff Report를 열어 차이를 확인합니다.
5. AutoChange에서 N은 비교만, Y는 새 Alarm 폴더 생성을 선택합니다.
6. 완료 메시지의 결과 경로와 보고서의 적용·제외 내역을 확인합니다.

[결과 저장 위치]
보고서와 결과 폴더는 exe가 있는 위치에 생성됩니다.
보고서: AlarmDiff_날짜_시각.txt
결과 폴더: Alarm (이미 있으면 날짜·시각 등의 접미사 추가)

[Diff Report 항목]
1. 알람 파일 List 차이: 한쪽에만 있는 CSV 파일
2. 파일별 StopMode 차이: 공통 CSV의 동일 ID에 대한 Run/Setup/Default 차이
3. Alarm ID 차이: 공통 CSV 안에서 한쪽에만 있는 ID·이름·행 번호
4. 컬럼 내용 차이: 동일 ID의 StopMode 외 컬럼 값 차이
각 항목에는 해당 차이가 있는 파일만 표시합니다.

[AutoChange 적용 규칙]
Path2의 파일·행 구성을 유지하고, 공통 CSV의 동일 ID에 Path1 StopMode 3개를 적용합니다.
Path2에만 있는 파일·ID는 유지하며, Path1에만 있는 파일·ID는 추가하지 않습니다.
CSV 오류·중복 ID·인코딩 문제로 제외된 파일은 Path2 그대로 복사합니다.
입력 원본은 변경하지 않으며, 결과 폴더를 장비에 자동 적용하지 않습니다.
