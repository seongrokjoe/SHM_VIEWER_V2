SCTC_Alarm_Compare.exe 사용 방법
========================================

1. 프로그램의 용도

기존 장비의 Alarm 폴더와 패치 Alarm 폴더를 비교하여 차이 보고서를 만듭니다.
필요하면 패치 폴더를 기준으로 새 Alarm 폴더를 생성하고, 일치하는 Alarm ID의
StopMode_Run / StopMode_Setup / StopMode_Default를 기존 장비의 값으로 적용합니다.

입력 경로의 의미:
    Path1 = OLD/Equipment = 기존 장비 Alarm 폴더
    Path2 = NEW/PatchSet  = 패치 Alarm 폴더

AutoChange의 적용 방향:
    Path2의 파일·행 구성 + Path1의 동일 ID에 대한 StopMode 3개
    → 새 결과 Alarm 폴더

Path1과 Path2의 순서에 따라 적용되는 StopMode가 달라지므로 위 역할에 맞게 입력합니다.
입력 원본은 읽기만 하며, 생성한 결과를 장비 원본에 자동으로 덮어쓰지 않습니다.


2. 실행 준비

(1) Windows 64비트 PC에 SCTC_Alarm_Compare.exe를 복사합니다.
    실행을 위해 .NET, Python 또는 Visual Studio를 별도로 설치할 필요는 없습니다.

(2) 실행 파일은 두 입력 Alarm 폴더 밖의 쓰기 가능한 폴더에 둡니다.
    두 입력 폴더의 하위 폴더에도 실행 파일을 두지 않습니다.
    비교 보고서와 결과 Alarm 폴더는 실행 파일이 있는 위치에 생성됩니다.

(3) 입력할 경로는 CSV 파일 경로가 아니라 Alarm 폴더의 절대경로입니다.
    하위 폴더까지 함께 처리하므로 두 폴더에서 같은 기준 위치를 선택합니다.

폴더 배치 예시:
    C:\AlarmCompare\SCTC_Alarm_Compare.exe
    D:\Equipment\Alarm\                  ← Path1
    D:\PatchSet\Alarm\                   ← Path2

한글과 공백이 포함된 경로, 네트워크 공유 경로(UNC)를 사용할 수 있습니다.
경로 전체를 큰따옴표로 감싸서 붙여 넣어도 됩니다.

입력 예시:
    D:\기존 장비\Alarm
    "D:\패치 자료\Alarm"
    \\Server\Share\Equipment\Alarm


3. 실행 순서

(1) SCTC_Alarm_Compare.exe를 더블클릭합니다.
    콘솔 창이 열립니다. 시작 화면에는 프로젝트명 AlarmCsvMerge가 표시될 수 있습니다.

(2) 다음 안내가 나오면 기존 장비 Alarm 폴더 경로를 입력하고 Enter를 누릅니다.
    Alarm Folder Path1 (OLD/Equipment):

(3) 다음 안내가 나오면 패치 Alarm 폴더 경로를 입력하고 Enter를 누릅니다.
    Alarm Folder Path2 (NEW/PatchSet):

(4) 파일 읽기와 비교가 끝나면 콘솔에 요약과 Diff 보고서 경로가 표시됩니다.
    실행 파일 옆에 생성된 AlarmDiff_날짜_시각.txt를 메모장으로 열어 확인합니다.
    AutoChange 선택 전에 보고서를 확인할 수 있습니다.

(5) 다음 안내에서 목적에 맞는 문자를 입력하고 Enter를 누릅니다.
    AutoChange? [Y/N]:

    N 또는 n:
        비교 보고서만 저장합니다. 결과 Alarm 폴더는 생성하지 않습니다.
        보고서에 [AUTOCHANGE NOT REQUESTED]가 추가됩니다.

    Y 또는 y:
        Path2의 구성을 기준으로 새 Alarm 폴더를 생성합니다.
        공통 파일의 동일 ID에 대해 StopMode 3개를 Path1 원문으로 적용합니다.
        완료되면 콘솔에 생성 완료 메시지와 실제 결과 폴더 경로가 표시됩니다.

    Y/N 이외의 값을 입력하면 다시 입력을 요청합니다.

(6) Y를 선택했다면 같은 보고서의 AUTOCHANGE: NEW -> OUTPUT 영역을 확인합니다.
    성공 시 [AUTOCHANGE COMPLETE]가 기록됩니다.
    생성된 파일과 제외 내역을 확인한 후 결과 사용 여부를 결정합니다.

(7) 콘솔에 "Enter 키를 누르면 종료합니다."가 표시되면 Enter를 눌러 종료합니다.

입력 전체를 읽지 못한 경우에는 보고서를 남기고 AutoChange 없이 종료합니다.
콘솔에 표시되는 실패 또는 제외 안내와 보고서의 오류 내역을 확인합니다.


4. 생성 파일과 저장 위치

실행 파일이 C:\AlarmCompare에 있는 경우:

    비교 보고서:
        C:\AlarmCompare\AlarmDiff_20261014_153000.txt

    Y 선택 시 첫 번째 결과 폴더:
        C:\AlarmCompare\Alarm\

    Alarm 폴더가 이미 있으면:
        C:\AlarmCompare\Alarm_20261014_153000\

보고서와 결과 폴더 이름의 날짜·시각은 실행 PC의 현지 시각입니다.
이름이 겹치면 숫자 접미사가 붙은 새 이름을 사용하며 기존 결과를 덮어쓰지 않습니다.
정확한 저장 경로는 실행 완료 시 콘솔에 표시되는 경로를 확인합니다.
저장 위치는 실행 파일의 위치이며, 명령 프롬프트의 현재 폴더와는 무관합니다.

보고서는 UTF-8 BOM / CRLF 형식의 텍스트 파일입니다.
Path2의 하위 폴더와 빈 폴더도 결과에 포함됩니다.


5. Diff Report 읽는 방법

보고서 상단에서 Path1과 Path2의 실제 경로를 확인합니다.
아래 네 카테고리는 항상 표시되며, 각 종류의 차이가 있는 파일만 나열됩니다.
해당 카테고리에 차이가 없으면 파일명 대신 "차이 없음"이 표시됩니다.

5-1. <알람 파일 List 차이>

    CSV 파일만 대상으로 한쪽에만 존재하는 파일을 표시합니다.
    파일명은 입력 Alarm 폴더를 기준으로 한 상대경로입니다.

    [Path1 ONLY] = 기존 장비 폴더에만 있는 CSV
    [Path2 ONLY] = 패치 폴더에만 있는 CSV

    비CSV 파일은 이 목록에 표시하지 않습니다.

5-2. <파일별 StopMode 차이>

    양쪽에 공통으로 존재하는 CSV의 동일 ID를 비교합니다.
    StopMode_Run / StopMode_Setup / StopMode_Default 중 값이 다른 컬럼을 표시합니다.

    예시:
        --- File: BM.csv ---
        [STOPMODE] ID="1001" Column=8 Name="StopMode_Run" Path1 Line=2 Path2 Line=4
          Path1: "EMGStop:5|6"
          Path2: "DisplayOnly:1"

    위 예시는 BM.csv의 ID 1001에 대해 Run 값이 다르다는 뜻입니다.
    Y를 선택하면 새 결과의 Run에는 Path1 값인 EMGStop:5|6이 들어갑니다.
    Setup과 Default도 동일 ID의 Path1 값을 적용합니다.

5-3. <파일별로 Alarm ID 기준으로 한쪽에만 있는 리스트>

    양쪽에 공통으로 존재하는 CSV 내부에서 한쪽에만 있는 ID를 표시합니다.

    [Path1 ONLY ID] = Path1 파일 내부에만 있는 ID
    [Path2 ONLY ID] = Path2 파일 내부에만 있는 ID

    각 항목에는 ID, Name(이름), Line(원본 행 번호)만 기록합니다.
    Name은 CSV의 두 번째 컬럼 값입니다.

    예시:
        --- File: BM.csv ---
        [Path1 ONLY ID]
        ID="9000" Name="Old alarm" Line=3
        [Path2 ONLY ID]
        ID="3003" Name="New alarm" Line=2

    파일 자체가 한쪽에만 존재하면 5-1에 파일명만 표시합니다.
    해당 파일의 모든 ID를 이 카테고리에 펼쳐 쓰지 않습니다.

5-4. <파일별 Alarm ID 기준으로 컬럼별 내용이 다른 리스트>

    공통 CSV의 동일 ID에서 StopMode를 제외한 컬럼의 값 차이를 표시합니다.
    [OTHER COLUMN] 뒤에 ID, 컬럼 번호·이름, 양쪽 Line과 값이 기록됩니다.
    StopMode 차이는 5-2에서 확인합니다.

    <MISSING COLUMN>은 해당 위치의 컬럼이 없다는 뜻입니다.
    컬럼이 존재하지만 값이 빈 경우와 구분합니다.

공통 표기와 비교 규칙:

    - Column과 Line은 1부터 시작합니다.
    - Line은 주석과 빈 줄을 포함한 원본 파일의 실제 행 번호입니다.
    - 파일은 대소문자를 구분하지 않는 상대경로로 대응합니다.
      Sub\BM.csv와 sub\bm.CSV는 대응하지만 A\BM.csv와 B\BM.csv는 별개입니다.
    - ID는 앞뒤 공백을 제거한 문자열로 대응합니다.
      001과 1, A001과 a001은 서로 다른 ID입니다. ID의 행 순서는 무관합니다.
    - 컬럼 값은 앞뒤 공백을 무시하지만 대소문자와 | 항목 순서는 구분합니다.
    - 컬럼은 같은 위치끼리 비교합니다. 헤더명 변경 자체는 차이로 표시하지 않습니다.
    - 따옴표 표기만 다르고 해석한 값이 같으면 값 차이로 표시하지 않습니다.
    - 보고서 값의 \" 또는 \t 등은 텍스트 표시용 이스케이프입니다.
      CSV 원문에 역슬래시가 추가되었다는 뜻은 아닙니다.

오류 및 비교 제외 내역:

    오류 파일은 네 카테고리 뒤의 별도 영역에 기록됩니다.
    [NOT COMPARED]는 CSV 오류 때문에 해당 파일의 값·ID를 비교하지 못했다는 뜻입니다.
    [AUTOCHANGE EXCLUDED]는 병합 검증 또는 인코딩 문제 등으로 자동변경이 제외된 경우입니다.
    입력이나 비교가 불완전하면 관련 빈 카테고리에
    "비교 가능한 항목에서 차이 없음 — 오류 내역 참조"가 표시됩니다.
    이 문구는 모든 파일이 같다는 의미가 아닙니다.

SUMMARY:

    전체 파일, CSV, ID 집계와 차이 건수를 표시합니다.
    개별 목록에서 생략한 정상 파일도 전체 집계에 포함됩니다.
    All files에는 비CSV 파일도 포함됩니다.
    Comparable IDs (common CSVs)의 전용 ID 건수는 공통 CSV 내부의 ID 차이만 집계합니다.
    Generation: available은 결과 생성이 가능하다는 뜻입니다.
    available이어도 일부 CSV가 자동변경에서 제외될 수 있으므로 제외 건수도 확인합니다.
    Generation: DISABLED는 입력 목록이 불완전하여 결과 생성이 금지되었다는 뜻입니다.


6. AutoChange 적용 규칙

    공통 CSV + 양쪽에서 유일하게 존재하는 동일 ID:
        Path1의 StopMode 3개를 새 결과에 적용합니다.
        이름, 설명 등 StopMode 이외의 필드는 Path2 값을 유지합니다.

    Path2에만 있는 파일 또는 ID:
        Path2 그대로 결과에 포함합니다.

    Path1에만 있는 파일 또는 ID:
        새 결과에 추가하지 않습니다.

    어느 한쪽 CSV에 중복 ID, CSV 문법 오류, 컬럼 수 오류, 인코딩 문제가 있는 경우:
        해당 파일 전체를 자동변경에서 제외합니다.
        Path2에 파일이 있으면 그 파일을 바이트 그대로 결과에 복사합니다.
        정상 행만 골라 부분 적용하지 않습니다.

    비CSV 파일:
        Path2의 파일을 바이트 그대로 복사합니다.

빈 StopMode도 Path1의 값으로 적용합니다.
Path1의 StopMode가 비어 있으면 결과도 빈 값이 됩니다.

값이 같아 Diff에 표시되지 않더라도 공백·따옴표 표기가 다르면
Path1의 StopMode 원문이 적용될 수 있습니다.
AUTOCHANGE 영역의 VALUE CHANGED는 값 변경, FORMAT ONLY는 표기 변경입니다.

Path2의 StopMode 외 필드, 행 순서, 헤더, 주석, 빈 줄, 인코딩, BOM,
줄별 줄바꿈과 마지막 개행 여부를 보존합니다.
파일 내용과 폴더 구성을 복사하며, 파일 시각·NTFS 권한 등은 복제 대상이 아닙니다.

Y/N 입력을 기다리는 동안 입력 파일을 변경해도 비교 시 읽어 둔 내용을 사용합니다.
변경된 파일로 다시 작업하려면 프로그램을 다시 실행합니다.


7. 입력 CSV 형식과 큰따옴표 규칙

첫 번째 비어 있지 않은 비주석 행을 헤더로 사용합니다.
앞쪽 공백 뒤 #으로 시작하는 행은 주석입니다.
헤더는 최소 10개 컬럼이어야 하며, 데이터 행의 컬럼 수는 해당 파일의 헤더와 같아야 합니다.

고정 컬럼 위치:
    1번째  : Alarm ID
    2번째  : 이름(Name)
    8번째  : StopMode_Run
    9번째  : StopMode_Setup
    10번째 : StopMode_Default

헤더 이름보다 컬럼 위치를 기준으로 처리하므로 위 위치를 유지합니다.
CSV의 필드 구분자는 쉼표(,)입니다.

큰따옴표 사용법:

    - 값에 큰따옴표 하나(")를 넣으려면 두 개("")를 연속해서 씁니다.
    - 값에 쉼표가 있으면 값 전체를 큰따옴표로 감쌉니다.
    - 전체를 감싸지 않은 필드에서도 내부의 ""를 큰따옴표 하나로 처리합니다.

    CSV 필드 원문          → 해석한 값
    abc""def               → abc"def
    "abc,def"              → abc,def
    "abc ""def"", ghi"     → abc "def", ghi
    ""abc""               → "abc"
    ""                     → 빈 값
    """"                   → "

완전한 큰따옴표 필드 해석을 우선하므로 ""는 빈 값입니다.
감싸지 않은 필드의 단독 큰따옴표, 닫히지 않은 큰따옴표,
닫힘 뒤의 잘못된 문자, 여러 물리적 줄에 걸친 필드는 오류입니다.
빈 필드와 마지막 빈 필드도 지원합니다.

지원 인코딩:
    UTF-8(BOM 유무), CP949, BOM 있는 UTF-16 LE/BE

UTF-32, BOM 없는 UTF-16, 잘못된 문자 데이터는 지원하지 않습니다.
출력 인코딩으로 Path1의 StopMode를 손실 없이 표현할 수 없으면
해당 Path2 파일은 자동변경에서 제외하고 원본 바이트 그대로 복사합니다.


8. 자주 발생하는 상황과 처리 방법

경로 오류:
    실제 존재하는 폴더의 절대경로를 입력했는지 확인합니다.
    CSV 파일 경로나 상대경로 대신 Alarm 폴더 경로를 입력합니다.
    대화형 실행에서는 오류 메시지를 확인한 뒤 경로를 다시 입력할 수 있습니다.

"exe 폴더가 입력 Alarm 폴더 안에 있습니다" 안내:
    실행 파일을 두 입력 Alarm 폴더 밖의 별도 폴더로 옮긴 뒤 다시 실행합니다.

입력 전체를 읽지 못했거나 Generation: DISABLED가 표시됨:
    보고서에서 읽기 실패 경로, 접근 권한, 다른 프로그램의 파일 잠금을 확인합니다.
    링크 또는 정션이 포함된 경로는 지원하지 않습니다.
    일반 폴더와 실제 파일로 준비한 후 다시 실행합니다.

Duplicate ID:
    같은 파일에서 동일 ID가 중복된 경우입니다.
    앞뒤 공백과 따옴표 표기를 해석한 뒤 같은 ID가 되는 경우도 포함됩니다.
    표시된 원본 행 번호를 확인하여 중복을 정리한 후 다시 실행합니다.

column count mismatch:
    표시된 행의 컬럼 수가 헤더와 다릅니다.
    값에 포함된 쉼표를 큰따옴표로 감쌌는지, 불필요한 쉼표가 있는지 확인합니다.

quote inside an unquoted field / unclosed quoted field 등:
    단독 큰따옴표, 큰따옴표의 짝, 닫힘 뒤 문자를 확인합니다.
    내부 큰따옴표는 ""로 표현하고, 쉼표가 포함된 값은 전체를 감쌉니다.

일부 CSV가 자동변경에서 제외되었다는 안내:
    오류 및 비교 제외 내역과 AUTOCHANGE 영역을 확인합니다.
    제외된 Path2 CSV는 결과 폴더에 원문 그대로 복사됩니다.

보고서 또는 결과 폴더 생성 실패:
    실행 파일이 있는 폴더의 쓰기 권한과 디스크 여유 공간을 확인합니다.
    실패 후 남아 있는 결과 경로가 안내되면 그 경로와 보고서를 확인합니다.


9. 종료 코드

명령 프롬프트나 자동 실행에서 사용할 때의 종료 코드입니다.

    0 : 비교 또는 결과 생성 완료. N을 선택한 경우도 포함합니다.
    1 : 경로·읽기·쓰기 오류 등으로 실행 또는 결과 생성 실패.
    2 : 작업은 끝났지만 Path2 CSV 중 자동변경에서 제외된 파일이 있음.
        N을 선택해도 비교 중 제외된 Path2 CSV가 있으면 2를 반환할 수 있습니다.

작업이 끝난 후에는 콘솔에 표시된 보고서 경로와 결과 폴더 경로를 기준으로 확인합니다.
